# Private Archive

This directory preserves historical content that is no longer published on the public site.

The files kept here are not part of Hexo's `source/` directory, so Hexo does not generate pages from them.

Content is retained here for version history and future reference. Keeping a language archive here does not mean the current website still provides that language.

The `languages/ja/` archive keeps the discontinued Japanese site and post sources. The `articles/` archive keeps specific removed articles that should no longer be generated by Hexo but still need a traceable historical copy.
